# Documentação e Modelagem - Stuxnet

1. **Diagrama de Classes (`diagrama-de-classes`):** Mapeia as classes de domínio (POJOs), atributos e relacionamentos (Cliente, Produto, Pedido, etc.).
2. **Diagrama de Componentes (`diagrama-de-componentes`):** Representa as camadas da arquitetura MVC/REST da API (Controller, Service, Repository, DTO).
3. **DER - Modelo do Banco de Dados (`der-banco-de-dados`):** Diagrama Entidade-Relacionamento estruturando as tabelas do sistema.
